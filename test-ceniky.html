Ceníky

    Tento test zatím pouze zobrazuje seznam a otevírá náhledy existujícími Google odkazy. Nemůže měnit žádné soubory.

    Test volá pouze čtecí operace Google Drive API: files.get a files.list. API klíč je součástí dotazu do Google API (jako u každé čistě prohlížečové integrace), nikoli uložen do GitHubu. Nefunguje-li čtení bez přihlášení, test ukáže chybu; nepřesměruje tě na Google login.
